# pacman_java_GameProject
A classic Pac-Man game developed in Java using Java Swing.

## Project Overview
The goal of this project is to develop a playable Pac-Man game while applying Object-Oriented Programming (OOP) principles.

## Technologies Used
* Java
* Java Swing
* Git and GitHub

## OOP Concepts
The project aims to demonstrate the following OOP concepts:
* **Encapsulation**
* **Abstraction**
* **Inheritance**
* **Polymorphism**
* **Interfaces**

## Planned Features
* Player movement
* Maze and wall collision detection
* Ghost movement
* Food collection and scoring
* Win and game-over states
* Game restart functionality
